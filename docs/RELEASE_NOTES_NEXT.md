# QuickTranslate 发布说明（vNext）

> 基线版本：v1.9.3 → 目标版本：v1.9.4
> 发布模式：咨询模式（安装包未签名，仅 SHA256 校验）
> 最近同步：2026-10-12

## 新增特性

- **截图翻译 · 清晰区域 OCR 覆盖**：托盘菜单或 `Alt+S`（默认启用，可在设置中修改或关闭）框选同一显示器内的清晰文字区域，本地 OCR 识别后调用当前翻译模型，将译文覆盖回原截图位置。按 `Esc` 或右键取消框选，翻译完成后按 `Esc` 或单击覆盖层关闭。截图、OCR 文本和译文默认只保存在当前内存，不写入历史或日志。
- **本地 OCR 引擎**：Windows OCR 始终可用；可选 RapidOCR/ONNX 本地场景 OCR，含模型生命周期管理与引擎切换/回退（模型权重由用户在设置页主动下载，应用不会自动联网下载）。
- **翻译链路**：单元完成级流式翻译、结构化批量翻译与逐单元回退、译文覆盖层确定性布局与碰撞降级、进度显示与取消、URL/代码/路径/同语言文本的本地资格判定（保留原样、不发送 Provider）、截图源语言自动路由。
- **终端取词扩展**：放行编辑器内嵌终端与 webview 面板取词，复用"选中即复制"内容，避免误发 `Ctrl+C`。

## 优化改进

- **能力范围明确化**：正式支持范围限定为网页、IDE、文档段落与清晰单区域截图；复杂整页图片、密集论文版面和背景复杂的漫画不属于正式支持范围。
- 截图翻译资格判定、批处理拆分与会话生命周期重构；大批量截图拆分为独立批次并隔离超时重试。
- 无需翻译时的 OCR 提示流程简化。
- 补充 OCR 筛选统计与会话诊断。

## 修复

- 框选期间 `Esc`/右键取消；译文遮罩框文字截断。
- 截图翻译取消与 Worker 清理；失败恢复与超时处理。
- 已安装模型无法启用的运行时探测；RapidOCR 字典下载失败。
- 移除进程内 VEH 防止 CLR 崩溃。
