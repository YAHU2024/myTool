# QuickTranslate v1.9.0 发布说明

> 基线版本：v1.8.7  
> 最近同步：2026-08-16

## 新增特性

- 深度解析结果支持最多 10 轮连续追问，保留上下文并以流式方式追加回答。
- 追问历史提供节点状态和快速定位；最新失败或取消的尾轮可以原编号重试。
- 翻译、解析主结果和追问回答支持流式 Markdown 增量渲染。
- 已闭合的围栏代码块支持本地语法高亮，同时保留独立复制按钮和原始代码文本。
- 设置页新增思考模式开关，支持按供应商差异化发送思考参数（智谱/DeepSeek/SiliconFlow），默认关闭并持久化保存。
- 翻译悬浮窗新增当前会话模型快捷切换；生成中、已停止或已完成时均可主动换用已保存模型，且不会修改全局默认模型。
- 已保存模型配置支持 32 字符以内的自定义备注；留空时显示“模型名 · 供应商”。
- 翻译结果保持正常流式显示；完整响应与原文高度一致时保留正文，但不缓存或写入历史，应用不再自动重试或进入备用模型恢复流程。

## 优化改进

- 流式数据改为按增量合并呈现，减少长回答期间的重复字符串复制和 UI 刷新。
- 用户选择文本或操作代码块时暂停文档替换，避免选区跳变及复制按钮无法点击。
- 统一解析主结果、追问回答和 Markdown 正文的字体层级。
- 增加首 chunk、最大 chunk 间隔、UI 合并帧和呈现延迟等隐私安全的流式诊断指标。
- 悬浮窗底部改为固定单行中性状态栏，状态类型只改变圆点和文字颜色；模型入口使用紧凑按钮与设置页同系弹层，弹层锚点明确指向模型按钮，用户上滚后通过结果区右下角圆形箭头回到最新内容。
- 收敛解析和翻译系统提示词：核心任务与输入保护保持固定，自定义翻译提示词改为附加要求，不能再覆盖完整翻译、目标语言和防提示注入约束。
- 普通翻译请求直接以首条用户消息传递原文，并通过固定系统指令约束其仅作为待翻译数据；代码解释和术语解释继续使用输入分隔契约，避免改变现有智能解释行为。
- 自动判断翻译方向改为保守的本地文字系统判断：关闭时始终使用用户选择的目标语言；开启时仅对高置信度同语言文本使用备选语言，混合文本、未知文本及无法可靠区分的拉丁文字语言继续使用请求目标。
- 智能内容识别只把高置信度代码、命令、配置或术语切换到解释模式；低置信度候选和包含代码块、路径的 Markdown 技术文档继续完整翻译正文并保留技术片段。
- 翻译会话固定保存开始时的方向、提示词和模型语义；刷新及当前会话模型切换不会受之后的设置变化影响，缓存与历史统一记录实际目标语言。
- 日志查看器增加回显质量门禁和当前会话模型切换指标，相关事件只记录长度、相似度、模型和供应商主机等诊断元数据。

## 修复

- 修复终端宿主未被识别或空白区域误触红点时可能误发复制快捷键、导致前台命令中断的问题；取词现在固定一次宿主快照并按复制动作风险决策，普通编辑器不再依赖 UIA 选区矩形，明确拖选可在安全终端复制动作下执行一次；终端空白多击、无证据快捷键、可能中断命令的 Ctrl+C 和未验证按键始终拒绝注入。
- 修复成功的追问请求因控件替换异常而显示为"追问失败"的问题。
- 修复追问节点标签遮挡以及节点点击后选中状态不稳定的问题。
- 修复未闭合 Markdown 围栏在流式过程中无法稳定显示和复制的问题。
- 修复用户停止翻译后流式 Markdown 预览降级为未渲染原始标记的问题。
- 修复自定义解析方案处理短词组、字母数字组合或短句时可能解释系统提示词而非选中文本的问题。
- 修复 150% 等非整数缩放下模型菜单相对模型入口过度左移的问题，并将模型列表滚动条统一为 Windows 11 风格细滚动条。
- 修复“回到最新结果”按钮隐藏后正文仍永久保留底部占位、导致结果与状态栏之间出现多行空白的问题。
- 修复设置页选择已保存模型方案后模型 ID 消失，以及手动输入模型时误选供应商预置、清空 API Key 并保存非法展示名称的问题。
- 修复稍长的英文技术文档可能被整段识别为代码、被自定义提示词替换核心任务，或因错误的同语言分支直接返回原文的问题。

## 依赖

- 新增 `ColorCode.Core 2.0.15`，仅在本地解析已闭合代码块；不联网、不执行代码，也不动态下载语法定义。
- 未知语言、未闭合围栏、超过 50,000 字符的代码块或解析异常均回退为完整纯文本。
