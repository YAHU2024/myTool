# QuickTranslate v1.9.0 发布说明

> 基线版本：v1.8.7  
> 最近同步：2026-08-08

## 新增特性

- 深度解析结果支持最多 10 轮连续追问，保留上下文并以流式方式追加回答。
- 追问历史提供节点状态和快速定位；最新失败或取消的尾轮可以原编号重试。
- 翻译、解析主结果和追问回答支持流式 Markdown 增量渲染。
- 已闭合的围栏代码块支持本地语法高亮，同时保留独立复制按钮和原始代码文本。
- 设置页新增思考模式开关，支持按供应商差异化发送思考参数（智谱/DeepSeek/SiliconFlow），默认关闭并持久化保存。

## 优化改进

- 流式数据改为按增量合并呈现，减少长回答期间的重复字符串复制和 UI 刷新。
- 用户选择文本或操作代码块时暂停文档替换，避免选区跳变及复制按钮无法点击。
- 统一解析主结果、追问回答和 Markdown 正文的字体层级。
- 增加首 chunk、最大 chunk 间隔、UI 合并帧和呈现延迟等隐私安全的流式诊断指标。

## 修复

- 修复成功的追问请求因控件替换异常而显示为"追问失败"的问题。
- 修复追问节点标签遮挡以及节点点击后选中状态不稳定的问题。
- 修复未闭合 Markdown 围栏在流式过程中无法稳定显示和复制的问题。

## 依赖

- 新增 `ColorCode.Core 2.0.15`，仅在本地解析已闭合代码块；不联网、不执行代码，也不动态下载语法定义。
- 未知语言、未闭合围栏、超过 50,000 字符的代码块或解析异常均回退为完整纯文本。

## 验证状态

- `dotnet format --verify-no-changes`：通过。
- 隔离输出构建：0 error；保留仓库既有的 nullable 与 WPF DPI 配置 warning。
