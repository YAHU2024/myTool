# QuickTranslate 发布说明（v1.9.2）

> 基线版本：v1.9.1 → 目标版本：v1.9.2
> 发布模式：咨询模式（安装包未签名，仅 SHA256 校验）
> 最近同步：2026-08-23

## 新增特性

- **GitHub Issue 反馈系统**：新增托盘「反馈问题」与设置「帮助与反馈」双入口；反馈窗口支持内容预览、敏感信息提醒、逐字段复制与 GitHub Issue Form 提交；新增异常退出状态跟踪，下次启动给予恢复提示；日志查看与日志配置移入默认折叠的「开发者选项」。
- **模型思考区（推理隔离）**：新增独立思考区展示推理（reasoning）流，与正文、TTS、历史、缓存、日志及后续上下文隔离；支持生成期间展开、完成后收起，显示思考耗时；新增三态思考控制（跟随默认 / 开启 / 关闭），并迁移旧 `EnableThinking` 配置。
- **解析与追问体验**：
  - 解析模型切换扩展至代码 / 术语 / 分析模式，按会话模式保持独立模型快照，切换时保留后续上下文。
  - 追问支持「停止 → 重新编辑 / 重发」，停止后保留已输出内容，编辑历史轮次时自动移除依赖其上下文的后续追问。
  - Markdown 代码块改用只读 RichTextBox 渲染，支持精确选择与独立复制。
  - 选区红点触发收紧（仅在 UIA 确认真实文本选区、手势位置一致时显示，过滤自有窗口），并扩展网页文本选区定位。

## 优化改进

- 状态栏将生成秒数拆为固定可见字段，避免每秒计时刷新重置滚动动画；收窄模型选择器释放状态文字空间；同步完整状态的无障碍名称。
- 反馈窗口与设置窗口统一控件样式（圆角、悬停、焦点、Windows 11 细滚动条）。
- 中英文 README 同步更新（反馈、思考控制、解析追问交互说明）。

## 修复

- 反馈窗口滚动条与按钮布局统一。
- 模型快捷切换未应用独立思考控制（已在 profile 携带并保留三态思考偏好）。
- 选区红点误触（拖动 / 选择界面时）及网页文本框选区定位不准。
- Markdown 代码块选择不精确。
- 追问输入框上下键导航边界（单行 / 多行首末行 / 自动换行）。
- 模型菜单高 DPI 定位、短词翻译提示词、模型菜单末尾选项首次点击失效等历史缺陷。

## 依赖

- 无新增或升级依赖。安全约束保留：强制 `SQLitePCLRaw.bundle_e_sqlite3` 2.1.12 以修复 SQLite GHSA-2m69-gcr7-jv3q（CVE）。

## 验证情况

- 自动化测试：各提交记录显示 xUnit 通过（约 700–740 通过 / 3 跳过），`dotnet build` 0 error，`dotnet format --verify-no-changes` 与 `git diff --check` 通过。
- **未执行**（需人工验收）：真实 Provider 响应、WPF 渲染、混合 DPI 放置、托盘集成、安装 / 卸载、自动更新升级、辅助功能。
